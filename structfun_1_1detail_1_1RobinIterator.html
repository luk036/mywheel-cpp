Detailed Description

template<typename T>
struct fun::detail::RobinIterator< T >

Iterator for traversing elements in a Robin cycle.

Matches the Python RobinIterator pattern: stores both the current node (curr) and the excluded node (stop). Iteration stops when curr wraps around to stop.

Template Parameters
TType of the key/value stored in nodes.
